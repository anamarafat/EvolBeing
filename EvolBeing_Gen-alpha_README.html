2. What we created

The project is named EvolBeing (version Gen-alpha). It currently contains a minimal C++20 test executable. This README focuses on development tools and build setup, not source-code explanations.

EvolBeing/
├── main.cpp
├── CMakeLists.txt
└── build/                 (generated by CMake)
    ├── build.ninja
    ├── CMakeCache.txt
    └── EvolBeing.exe

Rename note: The names shown here are the intended Gen-alpha names. If your local folder and CMake target are still named EvoBeings, rename them when you update the project files; editing this README does not rename the local project.

main.cpp is the initial C++20 test source file. Its implementation is intentionally omitted from this setup guide.

CMakeLists.txt

cmake_minimum_required(VERSION 3.20)

project(EvolBeing LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 20)
set(CMAKE_CXX_STANDARD_REQUIRED ON)
set(CMAKE_CXX_EXTENSIONS OFF)

add_executable(EvolBeing main.cpp)

This defines the intended renamed C++ project, requires C++20, and instructs the build system to create EvolBeing.exe from main.cpp.

Important: selecting x64 MSVC

The first CMake configuration detected Hostx86/x86/cl.exe (32-bit). We fixed it by initializing the x64 MSVC environment in Windows CMD:

call "C:\Program Files (x86)\Microsoft Visual Studio\18\BuildTools\VC\Auxiliary\Build\vcvars64.bat"

After that, cl reported Microsoft C/C++ Optimizing Compiler 19.51.36260 for x64. We deleted the old build/ directory, reconfigured CMake and successfully ran the x64 executable.

The environment initialization applies to that CMD session. VS Code's automatic x64 compiler selection is the next configuration task.
